# DyScreen - Game-Based Dyslexia Screening Using Machine Learning

A browser-based screening aid that estimates a child's **risk** of dyslexia from six short
mini-games, using **classical machine learning only** (no deep learning).
It is **not** a diagnostic tool.

## 1. Project overview

```
Kaggle dataset -> preprocessing -> EDA -> feature engineering -> class balancing
-> feature selection -> 6 models + cross-validation + tuning -> evaluation -> saved model
-> Flask API <- browser mini-games -> same feature engineering -> prediction
-> risk level + probability + skill analysis -> screening report
```

## 2. Dataset

Rello et al. (2020), "Predicting risk of dyslexia with an online gamified test", PLOS ONE.
Kaggle: https://www.kaggle.com/datasets/luzrello/dyslexia

Put the **desktop** CSV at `data/dataset.csv` (see `data/PUT_DATASET_HERE.txt`).
It has 32 questions x 6 measures (Clicks, Hits, Misses, Score, Accuracy, Missrate),
4 demographic columns and the `Dyslexia` label (Yes/No).

## 4-7. How to run (in this order)

```
python preprocess.py           # Module 1 summary (shape, missing values, class counts)
python eda.py                  # Module 3 graphs -> results/
python feature_selection.py    # Module 6 -> results/
python train_model.py          # trains, evaluates, saves model -> models/ and results/
python app.py                  # starts the web app
```

Open **http://127.0.0.1:5000** in Chrome or Edge.

Without `data/dataset.csv` you can still run `python app.py`: the app starts in **DEMO MODE**.

| File | Purpose |

| `config.py` | All settings: paths, question-to-skill map, game-to-skill map, risk thresholds |
| `preprocess.py` | Load, clean, encode label, one-hot encode, stratified split, scaler |
| `feature_engineering.py` | ONE function (`build_features`) used for BOTH dataset rows and live game results |
| `eda.py` | EDA printouts and graphs |

| `templates/index.html`, `static/` | Six mini-games and the report page |
| `notebooks/analysis.ipynb` | Runs the whole pipeline step by step for the record |

### How live game data matches training data

Every game question produces `clicks`, `hits`, `misses` - exactly like each question in the dataset.
Questions are grouped into the same four skill areas on both sides:

| Skill area | Dataset questions | Browser games |
|---|---|---|
| Phonological Awareness | Q1-Q9 | Sound Match, Rhyme Time |
| Visual Discrimination | Q10-Q17 | Letter Hunt, Odd One Out |
| Executive Function | Q18-Q29 | What Comes Next |
| Working Memory | Q30-Q32 | Symbol Memory |

Q1-Q9, Q14-Q17 and Q30-Q32 follow the paper's description; the other groupings are an
approximation for this prototype and can be edited in `config.py`.

Model features: `age, phonological_score, visual_score, memory_score, executive_score,
overall_accuracy, miss_rate` where `score = hits / clicks` and `miss_rate = misses / clicks`.
Response time is shown in the report but is NOT a model input, because the dataset has no timing data.

## 9. ML algorithms

Logistic Regression, KNN, SVM, Decision Tree, Random Forest, XGBoost. Each is trained with
class weights and with SMOTE (KNN only with SMOTE). Tuned with GridSearchCV using the F2 score
(recall weighted 2x) inside 5-fold stratified cross-validation.
The final model = highest **cross-validated recall** among models with CV precision >= 0.20.

## 10. Evaluation metrics

Accuracy, precision, recall, F1, ROC-AUC, confusion matrix, classification report, ROC curves.
Recall on the dyslexia class is the main metric. All numbers are generated by
`train_model.py` into `results/model_comparison.csv` and `results/results_analysis.md`.

## 11. Ethical limitations

- Screening aid only; never a diagnosis. Referral to a professional is always recommended.
- Trained on Spanish-speaking participants; not validated on Indian children.
- Risk thresholds (0.40 / 0.70) are prototype values, not clinically validated.
- Only age and anonymous game scores are sent. No name, contact, photo or video.

## 12. Demo mode

If `models/dyslexia_model.joblib` does not exist, the app shows a yellow **Demo mode** label and
a clearly marked demo estimate (a simple rule, not ML). After `python train_model.py`, restart
`python app.py` and it switches to **Real model** mode automatically.

## What to explain for each 5-mark component

**UI + Backend connectivity:** the browser records clicks/hits/misses per question, sends JSON to
`POST /api/submit-game`; Flask validates it, calls the same `build_features()` used in training,
loads the saved pipeline with joblib, returns probability, risk level and skill analysis as JSON,
and the page renders it. Show the Network tab.

**Preprocessing + EDA:** label encoding, duplicate and missing-value checks, one-hot encoding,
stratified split, scaler fitted on training data only (inside the pipeline, so no leakage).
EDA shows the roughly 1 : 8 imbalance and how skill scores differ between classes.

**Model building:** six classical models, two imbalance strategies, GridSearchCV with stratified
5-fold CV, model chosen on cross-validated recall rather than accuracy. SMOTE runs only inside
training folds.

**Result analysis + insights:** open `results_analysis.md`: comparison table, confusion matrix
(how many at-risk participants were caught vs missed), why accuracy is misleading here, feature
importance, and the practical insights and limitations.

## Common errors and fixes

| Error | Fix |
|---|---|
| `Dataset not found` | Put the Kaggle desktop CSV at `data/dataset.csv` exactly |
| `No 'Dyslexia' label column` | You used the wrong file; use the desktop CSV from the Rello dataset |
| `ModuleNotFoundError: imblearn` | `pip install imbalanced-learn` |
| `shap` fails to install | Remove it from requirements; training still works (SHAP step is skipped) |
| XGBoost install error on Windows | `pip install --upgrade pip` then `pip install xgboost` |
| App still says Demo mode after training | Stop `app.py` (Ctrl+C) and start it again |
| `Feature columns changed - retrain` | You edited `FEATURE_COLUMNS`; run `python train_model.py` again |
| Port 5000 already in use | Change `port=5000` to `port=5001` in `app.py` |
| No sound in Sound Match | Click "Play the sounds"; check volume; use Chrome or Edge |
| Page opens but games do not start | Open via `http://127.0.0.1:5000`, not by double-clicking `index.html` |
